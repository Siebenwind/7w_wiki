## Volltext (bereinigt)

Hallo liebe Spielerschaft!

Leider müssen wir euch mitteilen, dass unser Übereinkommen mit Spielviel gestern ausgelaufen ist. Wir bedanken uns natürlich bei Spielviel für den jahrelangen ausgezeichneten Support und wünschen Spielviel noch alles Gute. Was bedeutet das nun für Siebenwind? Der Server wird heute im Laufe des Tages abgeschaltet. Wir haben noch rechtzeitig alle Daten gesichert und werden den Server vorrübergehend woanders hosten, bis wir eine zufriedenstellende Lösung gefunden haben. Leider dauert die Namensauflösung für schnellerwind.mind.de etwas, so dass es sein kann, dass der Server einige Stunden heute nicht erreichbar sein wird. Danach wird der Server möglicherweise an der Performance leiden zu den Hauptspielzeiten. Sollte es etwas neues geben, halten wir euch auf dem Laufenden.

Danke für Euer Verständnis

Solos
