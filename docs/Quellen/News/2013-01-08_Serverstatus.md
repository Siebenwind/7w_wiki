## Volltext (bereinigt)

Die meisten von euch dürften den entsprechenden Thread dazu schon gesehen haben: Link

Wie’s aussieht, haben wir mit Hilfe der grandiosen Spielviel (bzw. SINMA)-Jungs eine temporäre Lösung gefunden, werden aber um eine aufwändige und nachhaltige Lösung nicht drumrum kommen. Sprich die Portierung unseres Siebenwind-Servers und der Verwaltungsfunktionen auf einen aktuellen Kernel/Distribution. Das wird eines der grossen Projekte für uns im 2013 werden.

Zum Status des Servers halte ich euch hier auf dem Laufenden.

 

Update 22:45 Uhr:

Zurzeit wird der Siebenwind-Server in eine KVM kopiert, um dann dort zu laufen. Dort kann dann zur Not rebootet werden, falls sich der Verdacht erhärtet, dass das Problem im Zusammenhang mit einer sehr grossen Kernel-Uptime (im Verbund mit unserer betagten GenToo-Installation) steht. Das ist dann aber wie gesagt erstmal nur eine Umgehungslösung. Aber wenn das läuft, haben wir Luft, um die nachhaltige (und aufwändigere) Lösung in Angriff zu nehmen.

 

Update 00:00 Uhr:

Kopieren auf die KVM läuft noch. Server wird erst im Verlauf vom Mittwoch wieder verfügbar sein. Das betrifft auch die Foren, die auf dem gleichen Server liegen.

 

Update 05:50 Uhr:

Der Umzug auf die andere KVM ist nach einigen Problemen (Spielviel hat bis vor einer Stunde dran gearbeitet) nun abgeschlossen. Ich hab eben reingeschaut und es schaut jetzt alles erstmal gut aus. Debug und Live laufen wieder im normalen Rahmen. Es spricht vieles dafür, dass es tatsächlich das vermutete (befürchtete) Problem war. Foren laufen auch wieder.

Ich werde den Server sicher noch etwas im Auge behalten, aber insgesamt könnt ihr wieder einloggen und loslegen.
