## Volltext (bereinigt)

Wir haben eine Gildenverwaltung eingebaut, die euch das Spiel in einer Gilde erleichtern soll. In der Gildenübersicht wird eine Liste aller erstellten Gilden angezeigt. Zu jeder Gilde kann man (wenn verfügbar) eine Kurzbeschreibung der Gilde aufrufen. Zudem gibt es jeweils einen Link zur Gilde im Accountbereich. Eigene Gilden werden farbig gekennzeichnet.

Das Kernstück des Gildensystems beinhaltet:

Mitglieder aufnehmen
(Mitglieder entlassen, kommt erst in einer späteren Version)
Mitgliedsrang ändern
Gildenitems verwalten
Gildentermine verwalten
Gildenaufträge verwalten/ansehen
Gildenschlösser
