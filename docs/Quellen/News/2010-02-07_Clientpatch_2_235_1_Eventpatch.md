# Clientpatch 2.235.1 – Eventpatch

_Beobachterprotokoll des Netz-Waechters. Quelle: offizielle Siebenwind-News._

## Meldungskern

Liebe Spielerschaft, ab sofort ist der Patch mit der Version 2.235.1 erhältlich. Es Handelt sich dabei um einen Eventpatch. Nebenbei wurden einige Baustellen erstellt damit ihr auf die Änderungen im nächsten regulären Patch vorbereitet werdet Die Version 2.235.1 beinhaltet: Staffbauten: Lavasee viel Spaß mit dem Patch wünscht, euer Designteam Nächster Patch vorraussichtlich um den 27.02
