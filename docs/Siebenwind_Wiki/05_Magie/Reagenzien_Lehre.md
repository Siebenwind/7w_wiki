# Reagenzien-Lehre (Fokus-Theorie)

**Epistemischer Status:** #überlieferung

Die **Reagenzien-Lehre** (nach Erzmagus [[Dunvallo_Linari]]) beschreibt die Nutzung natürlicher Rohstoffe als Hilfsmittel für die Zauberei. Linari postuliert, dass Reagenzien nicht absolut notwendig sind, einen Zauber jedoch erheblich vereinfachen, indem sie als "verschiebbare Knotenpunkte" im arkanen Gitter dienen.

## 1. Die Substitutions-Theorie
Da Reagenzien letztlich nur "Anker" für bestimmte astrale Muster sind, können sie ersetzt werden:
- **Astrale Kraft:** Ein Magier kann auf Reagenzien verzichten, muss dann aber deutlich mehr eigene Kraft aufwenden, um das Muster manuell zu weben.
- **Fokus-Gegenstände:** Ein gereinigter **Stab** oder eine Kristallkugel kann Reagenzien ersetzen, indem der Magier die benötigten Knotenpunkte an den Fokus bindet.
- **Selbst-Substitution:** Ein erfahrener Magier kann seinen eigenen Körper als Fokus nutzen, was jedoch Jahre der Vorbereitung erfordert.

## 2. Reagenzien und Runen-Zuordnung
Linari ordnet den klassischen Reagenzien spezifische Wörter der Macht ([[Rune|Runen]]) zu:

| Reagenz | Arkanes Muster | Rune (Alt-Galad) |
| :--- | :--- | :--- |
| **Ginseng** | Heilung / Leben | Man / Tamai |
| **Knoblauch** | Auflösung / Aufhebung | As / Uialai |
| **Nachtschatten** | Tod / Zerstörung | Corp / Naraskai |
| **Spinnenseide** | Licht / Hellsicht | Laf / Laidra |
| **Blutmoos** | Bewegung / Zeit | Rad / Tyr |
| **Alraune** | [[index]] / Stärke | Odal / Vy |
| **Schwefelasche** | Feuer / Zerstörung | Fe / Naraskai |
| **Schwarze Perle** | Ausdauer / Fülle | Vjera |

## 3. Gefahren
Linari warnt ausdrücklich davor, lebende, magiebegabte Wesen als Reagenzien-Substitut zu verwenden. Die aktive astrale Kraft des Wesens würde das gewebte Muster destabilisieren und zu unkontrollierbaren, oft fatalen Reaktionen führen.
