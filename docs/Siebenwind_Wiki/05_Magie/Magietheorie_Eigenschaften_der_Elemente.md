# Eigenschaften der Elemente

**Epistemischer Status:** #überlieferung

In diesem magietheoretischen Werk beschreibt [[Amanda_Dunkelbaum]] die praktische Anwendung der vier Elemente (plus Eis) in der Magie.

## Inhalt
Dunkelbaum ordnet jedem Element spezifische Wirkungsweisen und Runen zu:

### Wasser (Xa)
*   **Prinzip:** Reinheit, Leben, Heilung, Entgiftung.
*   **Anwendung:** Wundheilung, Neutralisation von Giften.
*   **Runen:** `Dagal Arh e Zeaseij, ur man`, `Dagal Naud, as Naud, ur Man`.
*   **Zitat:** *"Gift stellt ein Ungleichgewicht der Elemente dar."*

### Erde (Yhorn)
*   **Prinzip:** Schutz, Konstruktion, Festigkeit.
*   **Anwendung:** Rüstungszauber ("Steinhaut"), Erschaffung von Wällen ("Mauer aus Stein").
*   **Runen:** `Ing Sigil dra Yhorn, Ur Yhorn`, `Ing vjera perdo yhorn...ing geb dra yhorn`.

### Eis (Isaz)
*   **Prinzip:** Destruktion, Kälte.
*   **Anwendung:** Angriffszauber (Eissplitter), Gifte (durch Kälteschaudern/Ungleichgewicht).
*   **Runen:** `Narra odal radine hagal ki isaz`.

### Luft (Hagal)
*   **Prinzip:** Bewegung, Geist-Nähe.
*   **Anwendung:** Telekinese, Telepathie ("Luftbilder").

### Feuer (Fe / Laf)
*   **Prinzip:** Zerstörung, Licht, Wärme.
*   **Anwendung:** Blendung ("Reigen der Flammen"), Nachtsicht.
*   **Runen:** `Ing vjera Laf...ur Laf`, `Ur ji hian`.
