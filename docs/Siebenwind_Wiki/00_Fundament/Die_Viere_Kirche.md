# Die Viere Kirche

**Epistemischer Status:** #canon

`Die Viere Kirche` ist eine verkürzte oder umgangssprachliche Bezeichnung für die [[Kirche_der_Viere]], also die institutionalisierte Verehrung der Viere (Sahor) im Reich.
