# Alchemische Reagenzien und Foki

**Epistemischer Status:** #überlieferung (Autor: [[Dunvallo_Linari]], 13 n.H.)

In der hermetischen Magie dienen Reagenzien als materielle Brücken zum arkanem Gitter. Laut der Theorie von Erzmagus Linari sind Reagenzien keine bloßen Zutaten, sondern **bewegliche Knotenpunkte (Foki)** innerhalb der *Prima Materia*.

## 🧪 Die Funktion der Reagenzien

Reagenzien sind nicht zwingend notwendig, um Magie zu wirken, aber sie **entlasten den Magiewirker**. Durch ihre natürliche Arkanität stellen sie die benötigten arkanem Muster (Knoten) bereits zur Verfügung, sodass der Magier weniger eigene Astralenergie aufwenden muss, um das Gefüge zu manipulieren.

### Reagenzien als "Verschiebbare Knoten"
Linari entdeckte bei Untersuchungen an "Ruhenden Gebieten", dass Reagenzien im arkanem Gitter als Knotenpunkte sichtbar sind. Diese Knoten können im Raum bewegt werden (im Gegensatz zu festen Kraftorten).

| Reagenz | Arkanes Muster / Bedeutung | Wort der Macht (Rune) |
|:--- |:--- |:--- |
| **Ginseng** | Heilung / Leben | *Man* |
| **Alraune** | Magie / Stärke / Kraft | *Odal* / *Vy* |
| **Knoblauch** | Auflösung / Aufhebung | *As* / *Uialai* |
| **Nachtschatten** | Tod / Zerstörung | *Corp* / *Naraskai* |
| **Spinnenseide** | Licht / Klarheit / Anker | *Laf* / *Laidra* |
| **Blutmoos** | Bewegung / Zeit | *Rad* / *Tyr* |
| **Schwefelasche** | Feuer / Zerstörung | *Fe* / *Naraskai* |
| **Schwarze Perle** | Ausdauer / Intensität | *Vjera* / *Ur* |

## 🛠️ Substitution und Foki

Da Reagenzien lediglich Träger von Knotenmustern sind, können sie durch andere Foki ersetzt werden, sofern der Magier über die nötige Erfahrung verfügt, die Umgebungsknoten entsprechend zu manipulieren.

### Der Magierstab als Universalfokus
Ein gereinigter Magierstab fungiert als Ansammlung beweglicher Knotenpunkte. Ein erfahrener Magus kann die Knoten des Stabes nutzen, um das Muster einer Reagenzie zu imitieren (z.B. indem er beim Zaubern die Zacken eines Pentagramms mit dem Stab berührt).
- **Verschleiß**: Bei der Nutzung wird das arkane Gefüge des Stabes "verunreinigt", da Knoten aufgelöst und neu geordnet werden. Eine regelmäßige Reinigung (z.B. nach mithandrinischer Art) ist daher unerlässlich.

### Der Körper als Fokus
Theoretisch kann ein Magier seinen eigenen Körper als Fokus nutzen, indem er durch tiefe Meditation (z.B. bewussten Tiefschlaf) massive Anhäufungen von Knotenpunkten um seine Aura sammelt. Dies erfordert jedoch jahrelange Übung und birgt das Risiko unkontrollierbarer magischer Reaktionen, wenn der "interne" Geist das Gefüge unvorhergesehen verzerrt.
