# Seelenfresser

**Epistemischer Status:** #bote

## Hintergrund
Der **Seelenfresser** (auch als "Schattenbeißer" bekannt) ist eine unheimliche Gestalt aus den urbanen Legenden von [[Falkensee]]. Es handelt sich dabei um ein Geisterwesen, das angeblich im Schutz der Dunkelheit erscheint, um sich an den Seelen der Unvorsichtigen zu laben.

## Sichtungen
- **17 n.H.:** Während der Unruhen in [[Falkensee]] berichteten Zeugen von einer "unheimlichen Präsenz", die als Seelenfresser identifiziert wurde.
