# Ernennung von [[Ayk_Areson]]

!!! info "Metadaten"
    - **Epistemischer Status:** #bote
    - **Datum:** 29 n.H. (Bote 189)
    - **Ort:** [[Dunkeltief]]


## Verlauf
Nach dem Rücktritt von Jarl [[Halvard]] wurde **[[Ayk_Areson]]**, der Anführer der Exil-[[Nortraven]], zum neuen Jarl und Vogt von [[Dunkeltief]] gewählt.
Dies markiert die Wiedervereinigung der lange zerstrittenen [[Nortraven]]-Fraktionen ("Fornvinnr" und "Exilanten") und eine Annäherung an die Baronie.
