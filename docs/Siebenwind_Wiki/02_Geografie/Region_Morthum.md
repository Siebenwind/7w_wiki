# Region Morthum

**Epistemischer Status:** #canon

**Kategorie:** [[index]] / Baronie
**Hauptstadt:** Necris
**Herrscher:** Baron Vitallus von Morthum

## Beschreibung
Eine düstere und verfluchte Region.
*   **Der Atmende Tod:** Eine zehrende Seuche, die die Bevölkerung dezimiert hat.
*   **Dabus Gebirge:** Es wird weiterhin Bergbau betrieben, aber unter extremen Bedingungen.

## Wichtige Orte
*   **Necris:** Die staubbedeckte Hauptstadt, geprägt von Leichenfeuern und strengen Quarantänekontrollen.
