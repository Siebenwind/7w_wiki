# Malika Nohadi

!!! info "Metadaten"
    - **Titel:** Ritterin des Falken (†)
    - **Epistemischer Status:** #bote
    - **Zugehörigkeit:** Falkenorden / [[Brandenstein]]
    - **Zeitraum:** verstorben 16 n.H.


## Beschreibung
**Malika Nohadi** war eine hochverehrte Ritterin des Falken und eine treue Dienerin der Krone. Sie galt als Inbegriff von Weisheit, Güte und Mut.

## Ableben
Im Jahr 16 n.H. (Bote 136) wurde ihr Ableben offiziell von der Viergöttlichen Kirche bekannt gegeben. Das Volk von [[Brandenstein]] ehrte sie als standhafte Seele, die nun in Morsans Hallen eingegangen ist.
