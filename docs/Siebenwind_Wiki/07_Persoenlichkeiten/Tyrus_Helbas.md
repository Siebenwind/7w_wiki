# Tyrus Helbas

!!! info "Metadaten"
    - **Titel:** 2. Waffenmeister des [[Löwenorden]]
    - **Epistemischer Status:** #bote
    - **Zugehörigkeit:** [[Orden_der_Wachenden_Löwen]] / [[Bellum]]


## Beschreibung
**Tyrus Helbas**, ein Diener Bellums.
*   **18 n.H. (Bote 154):** Als **stellvertretender Waffenmeister** geriet er zusammen mit [[Lantea_Greifenstein]] in einen Kampf mit einem riesigen Spinnenwesen nahe dem Tempel, konnte jedoch durch das Eingreifen von [[Utrich_Rothnang]] gerettet werden.
*   **21 n.H. (Bote 182):** Kehrte aus dem Ruhestand (?) zurück, um das Amt des **2. Waffenmeisters** im Löwenorden zu übernehmen.
