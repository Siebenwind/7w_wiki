# Heeron Dherayne

**Titel:** Sprecher der Schattenjäger
**Epistemischer Status:** #bote
**Zugehörigkeit:** Siedlung [[Brandenstein]] / Ortsrat / [[Schattenjaeger]]
**Zeitraum:** aktiv 17 n.H.

## Beschreibung
*   **Sprecher der Schattenjäger (17 n.H.):** Heeron Dherayne fungiert als Sprecher der Schattenjäger im Ortsrat von [[Brandenstein]] ([[Siebenwind_Bote_152]]).
*   **Privates (20 n.H.):** Im Onar 20 n.H. wurde Heeron Vater einer Tochter (Mutter: Anouk). Zudem gab es Gerüchte über eine Liaison mit Freifrau [[Nhergas]] ([[Siebenwind_Bote_172]]).
