# Milorad

!!! info "Metadaten"
    - **Titel:** Waisenkind
    - **Epistemischer Status:** #bote
    - **Zugehörigkeit:** Waisenhaus "Bärenhöhle" / [[Falkensee]]


## Beschreibung
**Milorad** ist der Pflegesohn von [[Gorem_Motlow]]. Er wurde als Säugling in der Nähe eines Nortravendorfes ausgesetzt und von [[Gorem]] an Kindesstatt angenommen. Sein Schicksal inspirierte [[Gorem]] zur Eröffnung des ersten Waisenhauses auf [[Siebenwind]], der "Bärenhöhle" in [[Falkensee]] (Hausnummer 13).
