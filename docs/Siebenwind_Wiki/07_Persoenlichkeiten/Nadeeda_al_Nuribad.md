# Nadeeda al Nuribad

**Titel:** Soldatin / Verteidigerin
**Epistemischer Status:** #bote
**Zugehörigkeit:** [[Region_Malthust]]

## Beschreibung
**Nadeeda al Nuribad** ist eine Soldatin der Malthuster Armee. Bekanntheit erlangte sie im Jahr 21 n.H. (Bote 182) als Verteidigerin im Prozess gegen [[Talbin]]. Trotz ihrer Rolle als Untergebene der Ankläger verteidigte sie ihren Mandanten so geschickt, dass sie ein äußerst mildes Urteil erwirkte.
