# Quendan Comari

!!! info "Metadaten"

    - **Epistemischer Status:** #bote
    - **Zugehörigkeit:** [[Comari]] / [[Akademie_der_Arkanen_Künste]]


## Beschreibung
**Quendan Comari** ist ein Hochmagus. Er kehrte im Jahr 29 n.H. (Bote 188) aus dem Ruhestand an die Akademie zurück, um beim Wiederaufbau und der Lehre zu helfen.
