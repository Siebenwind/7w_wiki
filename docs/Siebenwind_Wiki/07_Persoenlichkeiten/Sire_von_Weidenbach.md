# Sire von Weidenbach

!!! info "Metadaten"

    - **Epistemischer Status:** #bote
    - **Zugehörigkeit:** [[Königliche_Akademie_der_Kriegskünste]]


## Beschreibung
**Sire von Weidenbach** war im Jahr 15 n.H. (Bote 121) der Leiter der Königlichen Akademie der Kriegskünste.
Er ist bekannt für seine strenge Disziplin; so entließ er 37 Schüler auf einmal wegen mangelnder Teilnahme am Unterricht.
