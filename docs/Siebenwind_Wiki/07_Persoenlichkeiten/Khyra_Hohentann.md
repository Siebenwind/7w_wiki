# Khyra Hohentann

!!! info "Metadaten"
    - **Titel:** Magierin / Frau Hauptmann
    - **Epistemischer Status:** #bote
    - **Zugehörigkeit:** [[Akademie_der_Arkanen_Künste]] / [[Graue_Garde]]


## Beschreibung
**Khyra Hohentann** ist eine Magierin (Novizin im Jahr 22 n.H.).
Sie heiratete im Jahr 22 n.H. (Bote 185) den Gardehauptmann [[Lucius_Gropp]] in einer Zeremonie (Rosenbund), die von Hochwürden [[Benion_Sandelholz]] geleitet wurde.
