# Rodeberg

!!! info "Metadaten"
    - **Titel:** Gardist / Feldscher
    - **Epistemischer Status:** #bote

## Beschreibung
**Rodeberg** ist ein Gardist der Rittergarde auf [[Siebenwind]].
*   **18 n.H. (Bote 161):** Er wurde mit dem kleinen Ehrenband für seinen Gardedienst sowie dem Kameradenband für seinen Einsatz als Feldscher ausgezeichnet.
