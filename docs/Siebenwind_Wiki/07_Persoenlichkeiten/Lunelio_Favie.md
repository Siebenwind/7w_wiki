# Lunelio Favie

**Titel:** Reisender / Chronist
**Epistemischer Status:** #bote
**Zugehörigkeit:** -
**Zeitraum:** aktiv 18 n.H.

## Beschreibung
**Lunelio Favie** ist ein Reisender, der seine Beobachtungen niederschreibt.
*   **18 n.H. (Bote 154):** Er besuchte [[Greifenklipp]] während des Dunkeltiefs und geriet dort in einen Angriff von Untoten. Er kämpfte an der Seite von [[Halgar]] gegen einen schwarzen Magier.
