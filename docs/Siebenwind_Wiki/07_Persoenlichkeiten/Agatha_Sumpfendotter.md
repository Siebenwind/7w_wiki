# Agatha Sumpfendotter

!!! info "Metadaten"
    - **Rolle:** Autorin
    - **Epistemischer Status:** #bote
    - **Zeitraum:** aktiv um 18 n.H.


## Beschreibung
Agatha Sumpfendotter ist eine bekannte Verfasserin von kurzweiligen Märchen und [[Erzählungen]].

## Wirken
Im Jahr 18 n.H. veröffentlichte sie das Buch **"[[Maerchen_und_wie_man_sie_vermeidet]]"**. Während das Werk für seine hochwertige Unterhaltung gelobt wurde, kritisierten Fachleute wie [[Abdolus_Nachengalle]] den Mangel an seriösem Sachgehalt in Bezug auf tatsächliche übernatürliche Phänomene. Dennoch erfreuen sich ihre Geschichten großer Beliebtheit beim einfachen Volk.
