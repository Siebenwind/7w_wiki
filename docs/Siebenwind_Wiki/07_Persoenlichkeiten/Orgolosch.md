# Orgolosch

**Titel:** Dämon (Erde)
**Epistemischer Status:** #bote
**Zugehörigkeit:** Übernatürliche Wesen / Elementare Mächte

## Beschreibung
**Orgolosch** ist ein Wesen von dämonischer Natur, das mit dem Element Erde in Verbindung gebracht wird. Er trat im Jahr 29 n.H. in Erscheinung (Bote 189).

## Wirken
