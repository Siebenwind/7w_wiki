# Iycheas Vrahn

!!! info "Metadaten"

    - **Zugehörigkeit:** [[Kirche_der_Viere]] / [[Brandenstein]]


## Beschreibung
**Iycheas Vrahn** ist ein Vertreter der Kirche in [[Brandenstein]].
Im Jahr 23 n.H. (Bote 187) versuchte er, den Konflikt zwischen der Tempelwache und den [[Nortraven]] als "Missverständnis" herunterzuspielen.
