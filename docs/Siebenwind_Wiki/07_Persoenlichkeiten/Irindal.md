# Irindal

Prinzessin Irindal, genannt die "Rose von Silberwald", war die Schwester von Ian Saranis und Tochter von [[Kedrin]]. Sie wurde von [[Galahad]] aus der Gefangenschaft des Nekromanten [[Azaris]] gerettet.
