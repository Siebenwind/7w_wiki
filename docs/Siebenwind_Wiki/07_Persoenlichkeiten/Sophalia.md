# Sophalia

!!! info "Metadaten"
    - **Titel:** Mutter / Bürgerin
    - **Epistemischer Status:** #bote
    - **Zugehörigkeit:** [[Siebenwind]]


## Beschreibung
**Sophalia** suchte im Jahr 15 n.H. (Bote 124) verzweifelt nach ihrem Kind **Leonoir** (Mädchen, blond, blaue Augen, ca. 4½ Jahre alt).
Auf der Flucht vor ungenannten "Häschern" musste sie das Kind im [[Greifenwald]] einer Gruppe Fremder anvertrauen. Kind und Gruppe verschwanden spurlos.
