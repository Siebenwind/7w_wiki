# Die Sprache Run

**Epistemischer Status:** #canon

Die Sprache **Run** (auch Altgaladonisch genannt) gilt laut Gelehrten wie [[Edomawyr]] als die älteste Sprache des Universums. Legenden besagen, dass sie die Sprache der [[Die_Gohor|Gohor]] (Götter/[[Drachen]]) ist und sich im Laufe der Zeitalter zum heutigen Galadonisch wandelte.

## Linguistischer Hintergrund

Der Name "Gohor" selbst leitet sich aus dem Run ab, wobei *Hor* für "Gott" steht. Es wird angenommen, dass die [[Drachen]] des ersten Zeitalters diese Sprache sprachen.

## Grammatik der Ursprache

Run zeichnet sich durch ein systematisches Endungsschema aus:

| Endung | Funktion |
| :--- | :--- |
| **~e** | Gegenwart & Imperativ |
| **~el** | Zukunft |
| **~er** | Vergangenheit |
| **~et** | Konjunktiv |
| **~ek** | Negation |

### Pronomina
*   **Ta'e:** Ich
*   **Da'e:** Du
*   **Ha'e / Ha'eri:** Er / Sie

## Auszug aus dem Wortschatz

*   **Hor:** Gott / Göttin
*   **Gala:** Heilig
*   **Ka:** Waffe
*   **Sah:** Seele
*   **Corp:** Tod
*   **Dyr:** Wille
*   **Enwunji:** Buch
*   **Odal:** Wissen

---
> [!TIP]
> Die Substantivierung erfolgt oft über die Endung **~ai** (Der, der etwas tut, z.B. *Odalj* - Magier).
