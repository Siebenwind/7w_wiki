# Erschaffene Diener ([[Golems]])

Das Schaffen von "Dienern" (meist als **[[Golems]]** deklariert) ist eine fortgeschrittene Form des [[Konstruktbau_und_Ariin|Konstruktbaus]]. Magister [[Nuir_Ekre]] definiert einen Golem als ein Artefakt mit einem rudimentären, künstlichen Verstand.

## 1. Golem-Kategorien

| Typ | Beschreibung | Materialien |
| :--- | :--- | :--- |
| **Festformgolem** | Besitzt eine konstante Form und feste Elemente. | Erde, Ton, Stein, Knochen, Glas. |
| **Fließformgolem** | Besteht aus unstetigen oder wechselnden Stoffen; benötigt ständige Konzentration des Magus. | Flüssiges Metall, Asche, Laub, Honig. |

## 2. Der künstliche Verstand
Ein Golem benötigt eine Matrix, um Befehle zu verarbeiten. Ekre beschreibt fünf Methoden:
1. **[[Geist]]-Bannung:** Ein niederer [[Geist]] wird gebunden und sein Wille "gebrochen".
2. **Tier-Transfer:** Der rudimentäre Verstand eines Tieres wird übertragen (tödlich für das Tier).
3. **Matrix-Befehle:** Feste Handlungsabläufe werden direkt in die arkan Matrix gewebt (unflexibel).
4. **Pergament-Befehl:** Ein physischer Befehl wird in den Körper eingelegt (leicht zu manipulieren).
5. **Seelen-Bannung:** Die Bindung menschlicher Seelen (gilt als blasphemische Perversion).

## 3. Der Hauch des Lebens
Um einen Golem zu aktivieren, muss ihm Lebenskraft eingeflößt werden:
- **Tierkraft:** Hält nur 3-4 Tage an.
- **Lebenshauch ([[Elfen]]):** Der Atem eines unsterblichen Wesens (z.B. Elf) kann einen Golem bis zu 2 Wochen beleben.
- **Macht-Transfer:** Der Magus überträgt eigene Energie (risikoreich).

## 4. Sicherheitsmechanismen
Zur Kontrolle übermächtiger [[Golems]] (insbesondere **Kampfgolems**) wird oft ein **Bernstein** als "Not-Aus" eingebaut. Dieser Edelstein repräsentiert den schlafenden [[Geist]] und kann die Matrix bei Bedarf kollabieren lassen.
