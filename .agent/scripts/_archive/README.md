# Skript-Archiv

Dieses Verzeichnis dient als "Friedhof" für veraltete, ersetzte oder einmalige Skripte. 

**Regeln für das Archiv:**
1. Skripte hier dürfen **nicht** in aktiven Workflows verwendet werden.
2. Wenn ein Skript wieder benötigt wird, muss es in das übergeordnete Verzeichnis (`.agent/scripts/`) zurück verschoben und die Funktionalität verifiziert werden.
3. Skripte werden hier konserviert, um historisches Wissen über Migrationsschritte (z.B. Frontmatter-Fixes, Batch-Verarbeitungen) zu bewahren.

*Siehe `SY_INTEROP.md` Norm 8 (Single Script Directory Policy).*
