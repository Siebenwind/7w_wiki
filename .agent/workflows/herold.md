# Workflow: /herold (Der Herold)

## Interop-Status
- runtime_commands:
  - `7w_wiki.py stats`
- method_only:
  - `/herold`

Dieser Workflow dient der visuellen und öffentlichen Pflege des Siebenwind-Wikis. Er sorgt für den "Wow-Effekt" und die proaktive Information der Community.

## 1. Visuelles Audit (Atelier)
- [ ] Prüfe die Homepage und wichtige Artikel auf visuelle Qualität.
- [ ] Fehlen atmosphärische Bilder? Nutze den **Art Director** Skill.
- [ ] Generiere neue Assets (Banner, Illustrationen) im **Codex Atlanticus** Stil.

## 2. Dokumentations-Politur
- [ ] Überarbeite die `README.md` für maximale Scannbarkeit und Ästhetik.
- [ ] Stelle sicher, dass neue Features (Skills, Workflows) prominent beworben werden.

## 3. News & Bekanntmachungen
- [ ] Erfasse Highlights aus dem `CHANGELOG.md`.
- [ ] Bereite Zusammenfassungen für das Forum oder News-Kanäle vor.
- [ ] Nutze `/delegate` für die Aufbereitung von News-Archiven.

## 4. Marken-Identität (Brand Identity)
- [ ] Überwache die Einhaltung des Farbschemas und der Typografie.
- [ ] Pflege das Logo, Favicon und andere Branding-Elemente.

## 5. Deployment-Support
- [ ] Prüfe den Status der GitHub Pages.
- [ ] Stelle sicher, dass die `mkdocs.yml` alle visuellen Features (Mermaid, Glossar, Darkmode) optimal nutzt.
