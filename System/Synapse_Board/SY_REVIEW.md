# 🔍 SY_REVIEW (Department Peer-Review)

**UUID:** 8e9f0a1b-2c3d-4e5f-6a7b-8c9d0e1f2a3b

Dieses Board dient der department-übergreifenden Qualitätssicherung. Hier werden Artikel und Merges zur Zweitmeinung ausgeschrieben.

## 🚀 Laufende Reviews
| ID | Gegenstand | von Department | Status | Auditor |
|---|---|---|---|---|
| *Keine* | - | - | - | - |

## 🤝 Vorgehen
1. Erstelle ein Ticket basierend auf `_TEMPLATE_AUDIT_REQUEST.md`.
2. Trage es hier ein mit Status `NEEDS_REVIEW`.
3. Der Auditor (meist Historiker oder Lektor) gibt sein Gutachten ab.
4. Nach Abschluss: Link im COORDINATION_HUB aktualisieren (falls nötig).

## Forschungsfreigaben

- Forschungsfreigaben und Rueckgaben werden zusaetzlich im Register `Logs/Reviews/RESEARCH_REVIEW_REGISTER.md` protokolliert.
- `Historian` darf fachlich kommentieren, aber nicht jede neue Quelle oder jedes Geschichtenmaterial wird automatisch zu einer Menschvorlage.
- Bei strittigen Themen und Kanonentscheidungen hat der Mensch das letzte Wort.
