# Artist Brief: GitHub-Homepage Grafiken (Siebenwind)

- **Datum:** 2026-02-15
- **Auftraggeber:** Netz-Waechter
- **Einsatzort:** GitHub Repository + GitHub Pages (`README.md`, `docs/index.md`, `docs/assets/`)

## Zielbild

Eine visuelle Sprache wie eine **Leonardo-Ingenieurszeichnung in Rötel**:

- skizzenhaft, aber technisch exakt
- leicht, papiernah, ohne schwere Flächen
- Daten/Struktur im Vordergrund, Kunst als präziser Überzug

## Stilvorgaben

- Palette: Rötel, Umbra, Pergament, dezente Kohlelinien
- Keine Neonfarben, kein Cyber-Glanz, keine Fantasy-Überladung
- Linienarbeit mit Konstruktionsgefühl: Raster, Maßhilfen, Annotationen
- Lesbarkeit priorisieren (Text muss auf Banner/Background klar bleiben)

## Konkrete Deliverables

1. `banner_main.png` (Repository Header)
- Format: 2400x900 px
- Nutzung: `assets/banner.png` und `docs/assets/banner.png`
- Inhalt: Siebenwind-Symbolik + technische Skizzenelemente + ruhiger Textbereich

2. `logo_roetel.png` (Wiki/Docs Logo)
- Format: 1024x1024 px, transparenter Hintergrund
- Nutzung: `docs/assets/logo.png`
- Muss in 32 px Höhe noch sauber erkennbar sein

3. `social_preview.png` (Open Graph / Share Preview)
- Format: 1280x640 px
- Nutzung: GitHub Link-Preview / externe Einbettung
- Motiv: Banner-Ästhetik, aber mit klarer zentraler Komposition

4. `bg_texture_light.png` (optionale Overlay-Textur)
- Format: 2048x2048 px, nahtlos kachelbar
- Nutzung: subtiler Hintergrund für zukünftige Wiki-Styles

## Qualitätskriterien

- Kontrasttest für helle Oberfläche bestanden
- Funktioniert auf Desktop und Mobile ohne Detailverlust
- Kein Wasserzeichen, keine Drittmarken, keine Signaturen im Sichtbereich
- Dateien in hoher Qualität, PNG verlustarm exportiert

## Ablage & Integration

- Neue Entwürfe nach `docs/assets/design_proposals/`
- Finale Dateien nach:
  - `assets/`
  - `docs/assets/`
- Changelog-Eintrag unter `CHANGELOG.md` bei finaler Übernahme
